# 05 · 两个案例，看看三步如何套用

[返回首页](../README.md) · [上一步：嵌网站](04-build-the-website.md) · [下一步：排错与发布](06-troubleshooting-and-publishing.md)

同一套方法可以讲完全不同的故事。下面的两个案例来自[飞书原文](https://qcnzs9lwq68y.feishu.cn/wiki/EnfDwph0TiFIkOk3qI9cfEYonse)：一个讲古建筑结构，一个讲手表产品。这里把它们改写成可照着套用的练习；案例中的具体建筑数据和产品参数，在正式发布前应核对资料。

## 案例 A：应县木塔

**想让访客看见什么？** 从木塔全貌出发，逐渐理解层叠结构，再走近梁柱和斗栱细节。

| 屏 | 讲述重点 | 模型动作 |
| --- | --- | --- |
| 01 · 初见 | 木塔全貌与主题句 | 稳定呈现完整模型 |
| 02 · 整体 | 建筑形态和背景 | 缓慢转动，换一个角度 |
| 03 · 结构 | 明层与暗层的关系 | 有依据的各层沿高度方向展开 |
| 04 · 细节 | 斗栱或梁柱 | 相机靠近真实建出的细节 |
| 05 · 价值 | 结构智慧与文化价值 | 回到整体与局部的对照 |
| 06 · 收尾 | 总结与延伸阅读 | 模型归位，展示行动入口 |

建模时，台基、每层可动的塔身和塔刹要先规划节点。细节有没有足够资料，决定它能否作为独立动画对象。若只是整塔照片，不要为爆炸图臆造不可见结构。

## 案例 B：FS50P 手表

**想让访客看见什么？** 先感受外观，再理解表壳、表盘、机芯等部件如何组成一只表。

| 屏 | 讲述重点 | 模型动作 |
| --- | --- | --- |
| 01 · 初见 | 正面外观与产品名 | 以完整模型开场 |
| 02 · 整体 | 侧面轮廓与材质 | 转到约 45° 视角 |
| 03 · 结构 | 表镜、表针、表盘、机芯、表壳等 | 各节点沿规划方向展开 |
| 04 · 细节 | 一个有资料可核对的部件 | 镜头推进 |
| 05 · 价值 | 佩戴场景和设计选择 | 模型与真实使用情境配合 |
| 06 · 收尾 | 总结和下一步操作 | 部件归位，显示按钮 |

手表外壳的复杂曲面可以尝试生成工具，表盘与表针等规则部分用 Blender 更易精确控制。材料、机芯参数和防水等级应取自真实产品资料，不照搬原文案例中的示意值。

## 换成自己的主题

试着填写这四句，再去修改[提示词①](../prompts/01-design.md)：

```text
我要展示的主体是：【       】
访客最想知道的是：【       】
能依据资料拆解的部件有：【       】
最后希望访客做的事是：【       】
```

只要能回答这四句，六屏内容就比较容易排出顺序。需要更多灵感时，回到[飞书原文](https://qcnzs9lwq68y.feishu.cn/wiki/EnfDwph0TiFIkOk3qI9cfEYonse)查看其图片和视频演示。
