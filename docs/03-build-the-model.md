# 03 · 做一个能拆、也能归位的模型

[返回首页](../README.md) · [上一步：设计六屏](02-design-six-screens.md) · [下一步：嵌网站](04-build-the-website.md)

爆炸图的秘诀很朴素：**想让哪个部件单独动，它就要在模型里是独立对象。** 一整块合并后的网格，到了网页里无法自然地把表针和表壳分开。

## 先选建模办法

| 部件特点 | 更适合先试 | 原因 |
| --- | --- | --- |
| 梁柱、台基、表针、简单外形 | Blender | 尺寸、位置、命名和层级容易精确控制 |
| 曲面外壳、有机形态、复杂材质 | 可选用 Aholo Lux3D 等生成工具 | 可快速得到候选形体，但仍需检查并修整 |
| 需要爆炸展开的完整物体 | 分件制作后在 Blender 组装 | 能保留独立节点和初始位置 |

先把规则结构做准，再补复杂细节。原文使用 Aholo Lux3D 的标准版与极速版；具体模式、额度和产出以[官方文档](https://labs.aholo.ai/api-docs/en/skills/lux3d)及你当前账户为准。它是可选工具，初学者可以先用 Blender 的简单几何体练习。

## 用手表示范分件规划

| 对象名 | 初始做法 | 展开方向 |
| --- | --- | --- |
| `glass` 表镜 | 独立对象 | 向上 |
| `hands` 表针 | 独立对象 | 向上 |
| `dial` 表盘 | 独立对象 | 向上 |
| `movement` 机芯 | 独立对象，可用参考图辅助生成 | 向上 |
| `case` 表壳 | 作为相对固定的主体 | 固定 |
| `back` 表背 | 独立对象 | 向下 |
| `strap_left`、`strap_right` 表带 | 两个独立对象 | 向两侧 |

这些名称只是示例。自己的主题可以换成“屋顶、柱网、台基”或“耳罩、驱动单元、头梁”。**有资料才拆；没有资料就只做真实可见的外观层。**

## 跟着做

1. **列清单。** 标出每个部件的名称、参考图、建模方式、父级对象和展开方向。
2. **逐件制作。** 规则形体在 Blender 中搭建；复杂部件如使用生成工具，也先逐件检查，再导入同一个 `.blend` 工程。
3. **组装到正确位置。** 对照参考图调整大小、方向和连接处。把层级关系整理清楚，不让相互独立的部件误被合并。
4. **记录初始状态。** 在组装完成后记录每个可动部件的初始位置、旋转和缩放。网页动画要从这些值计算，才能反向滚动归位。
5. **导出 GLB。** 在 Blender 中选择 `File → Export → glTF 2.0`，格式选择 `glTF Binary (.glb)`；检查导出范围、材质、贴图和 Y-up 转换。具体选项见 [Blender 官方 glTF 文档](https://docs.blender.org/manual/en/latest/addons/import_export/scene_gltf2.html)。
6. **重新打开检查。** 用 GLB 查看器检查颜色、比例、方向和节点名称；在网页里也要再检查一次。

想让 AI 帮你规划和操作，可以复制[提示词②：分件建模](../prompts/02-model.md)。原飞书文档提到配套的 `web3d-model-workflow` Skill；此仓库没有包含那份安装包，所以提示词②也提供了不依赖该 Skill 的做法。

## 资产清单示例

`asset-index.json` 可以从简单版本开始，至少记录**最终文件在哪里**：

```json
{
  "design": "design/",
  "modelSource": "model/object.blend",
  "modelWeb": "model/object.glb",
  "modelVersion": "v1",
  "movableParts": ["glass", "hands", "dial", "movement", "back"]
}
```

它只是一份项目内的路径清单，不会自动生成模型。实际文件名要与你的工程一致。

## 过关检查

- [ ] 需要单独运动的部件在 GLB 中仍是独立节点。
- [ ] 每个节点名称可识别，层级与父子关系合理。
- [ ] 已记录组装后的初始变换，模型旋转中心正常。
- [ ] 材质和贴图能在查看器或网页中显示。
- [ ] GLB 方向正确，体积适合目标设备。
- [ ] `.blend`、`.glb` 和 `asset-index.json` 都在项目目录中。

这些都通过，就可以让模型进入[网页阶段](04-build-the-website.md)。
