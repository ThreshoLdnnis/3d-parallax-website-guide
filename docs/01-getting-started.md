# 01 · 先从这里开始

[返回首页](../README.md) · [下一步：设计六屏故事](02-design-six-screens.md)

欢迎！这件事看起来同时涉及设计、建模和编程，先别急着一次学完。把它当成接力赛：**设计图说清楚要看到什么，3D 文件提供可移动的部件，网页负责让它们跟着滚动演出。**

## 最小目标

第一次练习，先做到以下三件事就很好：

1. 页面能显示一个真实的 GLB 模型。
2. 向下滚动时，模型从完整状态展开一个部件。
3. 向上滚动时，部件回到原位。

确认这条最短路径跑通，再扩展成六屏故事。**整张设计图或预录视频不能代替可交互的 3D 模型。**

## 工具清单

| 工具 | 负责什么 | 现在要做什么 |
| --- | --- | --- |
| [Blender](https://www.blender.org/download/) | 制作、组装与导出 3D 模型 | 安装后打开一次，确认可以新建工程 |
| [Node.js](https://nodejs.org/) | 运行本地网页开发环境 | 安装适合当前项目的版本，在终端运行 `node -v` |
| AI 工作环境 | 帮忙生成设计图、模型操作与网页代码 | 确认它能读取你的项目文件；本教程以原文的 Codex 工作流为例 |
| [Aholo Lux3D](https://labs.aholo.ai/api-docs/en/skills/lux3d)（可选） | 根据文字或参考图生成复杂部件 | 要使用时再按官方说明配置；没有它也能先用 Blender 练习 |
| [glTF Viewer](https://gltf-viewer.donmccurdy.com/) | 检查 GLB 是否真的能显示 | 等导出模型后再用 |

原文还提到 Image2 生图能力和一个配套建模 Skill。它们是原工作流中的工具名称；本仓库没有附带该 Skill，也没有替你安装插件。你可以使用当前可用的生图工具，并把[提示词①](../prompts/01-design.md)交给它。

## 先选一个主题

可以是建筑、手表、耳机，或者你自己的作品。建议挑**有清晰照片、能解释结构、只需少量部件**的对象。如果没有可靠的内部结构资料，就做外观分层或细节展示，不凭空编造内部零件。

准备一个项目文件夹：

```text
my-3d-story/
├── references/       # 主体照片、结构资料、品牌参考
├── design/           # 六张设计图、设计规范、逐屏文案
├── model/            # Blender 工程和导出的 GLB
├── web/              # 后续生成的网页项目
└── asset-index.json  # 文件位置与版本清单，可在建模后补齐
```

照片最好包括正面、侧面和局部细节；重要的是清楚、同一主体、来源可靠。参考网站只用来说明喜欢的色彩或排版，不直接搬用它的标志和文案。

## 开工前的五分钟检查

- [ ] Blender 能启动，能保存一个 `.blend` 文件。
- [ ] 终端运行 `node -v` 有版本号。
- [ ] 已选好展示对象，并放入至少一张清晰参考图。
- [ ] 知道哪些部件有资料依据，哪些只是外观推测。
- [ ] AI 工作环境能读取当前项目目录。

准备好了，就去[设计六屏故事](02-design-six-screens.md)。密钥等敏感信息只放在工具的安全配置中，不要写进公开仓库或提示词文件。
