# 提示词② · 规划分件并制作模型

[返回首页](../README.md) · [阅读建模步骤](../docs/03-build-the-model.md)

先上传参考照片和结构资料，再复制提示词。它把飞书原文的 Blender、Aholo Lux3D 和可选建模 Skill 工作流整理成不依赖特定安装包的版本。

```text
请在当前项目中，依据我提供的照片、结构资料和已确认的六屏设计稿，为【主体名称】制作适合网页展示的 3D 模型。请先检查当前项目里实际有哪些工具与文件，再执行；缺少必要资料时明确指出，不要编造不可见的内部结构。

先给出分件清单：每个部件的名称、参考依据、建模方式、父级关系、是否需要独立运动、爆炸图展开方向。规则几何优先用 Blender 精确搭建；复杂曲面或材质如有可用的 AI 3D 工具，可逐件生成后导入 Blender 检查和组装。没有相应插件时，用当前可用方法完成一个简单可演示的版本。

把所有部件放在同一个 Blender 工程中。对照参考资料调整比例和位置，使用清楚的对象名称；需要独立运动的部件不要合并。组装完成后，记录每个可动部件的初始 position、rotation 和 scale，以及它们的父子关系。请保存原始 .blend 工程。

导出网页可用的 glTF Binary (.glb)。检查导出范围、材质贴图、节点层级、坐标方向、模型原点和文件大小。用查看器重新打开 GLB，确认部件仍可单独识别。

在项目中生成或更新 asset-index.json，写明六张设计图、设计规范、逐屏文案、.blend、.glb 的实际路径和版本。最后报告：完成了哪些文件，哪些部件可拆，哪些地方仍需人工核对。不要只给操作建议；请实际保存和检查文件。
```

如果你已拥有原文提到的 `web3d-model-workflow` Skill，可在任务里明确指定使用它；本仓库没有提供那个 Skill 文件。按[建模篇的过关检查](../docs/03-build-the-model.md#过关检查)确认结果后，再去做网页。
