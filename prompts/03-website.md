# 提示词③ · 把设计和模型做成视差网站

[返回首页](../README.md) · [阅读建站步骤](../docs/04-build-the-website.md)

这条提示词要在**能读取六张设计图和 GLB 文件的项目**里使用。先确认建模篇已经过关。

```text
请继续在当前项目中工作，使用已经确认的六张设计图、设计规范、逐屏文案和 3D 模型，制作一个完整的 3D 视差滚动网站。请实际完成项目并启动本地预览，不要只给建议。

第一步：识别资产。读取当前项目和 asset-index.json，找到最终版设计图、文案、.blend、.glb 和可拆部件。清单缺失时扫描项目并补齐。优先使用已有成果，不重新生成已经完成的模型。文件确实缺失时，列出具体缺项。

第二步：准备模型。如果只有 Blender 工程，先导出 GLB；保留需要独立运动的节点、材质、层级和初始变换。检查贴图、比例、轴向、原点与部件名称。根据目标设备适当控制模型和贴图体积。

第三步：搭建页面。把六张设计图还原为六个连续的网页章节，沿用统一色板、字体、导航和按钮。文字使用真实 HTML 元素，3D 主体使用真实模型；不要用整张设计图或预录视频冒充交互模型。使用项目已有框架；如需新建，可选择 React + Vite + React Three Fiber + Drei。

第四步：实现滚动动画。以当前滚动进度 0～1 作为唯一时间轴。为每屏定义进入、停留和离开的区间，让背景、文字、相机、模型旋转和缩放平滑变化。章节之间不要突然跳画面，导航高亮随当前章节更新。

爆炸图只控制 GLB 中真实存在的独立节点。每个部件的位置、旋转和缩放都从记录好的初始变换及当前滚动进度计算，不在上一帧的位置上累计。向上滚动时必须准确归位。自由拖拽旋转或缩放要有清楚的入口，避免与页面滚动抢操作。

第五步：手机与加载状态。手机端重新安排文字和模型，缩小运动幅度；确保触摸滚动正常、页面能到达末尾。模型加载时显示简洁进度，失败时给出恢复办法。尊重减少动态效果设置。

第六步：实际检查。启动本地预览，在电脑和手机尺寸下检查模型、贴图、六屏顺序、导航、快速滚动、反向滚动、爆炸归位和交互冲突。用截图对照设计稿，修正明显偏差。交付本地预览地址、项目文件位置、已验证效果和仍存在的问题。只有我另行要求时才部署到外网。
```

网页生成后，照着[建站篇的过关检查](../docs/04-build-the-website.md#过关检查)亲自操作一遍；如果失败，再看[排错表](../docs/06-troubleshooting-and-publishing.md#常见问题速查)。
